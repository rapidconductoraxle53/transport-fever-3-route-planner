## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Route Designer** | Draw routes on a blank map canvas with waypoints and stops |
| **Profit Estimate** | Calculate expected revenue based on cargo volume and distance |
| **Frequency Optimizer** | Find the optimal vehicle frequency for any route length |
| **Network Overview** | Visualize your entire planned network on one canvas |
